This unsupervised machine learning project segments credit card customers according to their usage behavior. The analysis aims to support more personalized marketing strategies, product development, and risk management.

Methodology
- Exploratory data analysis and visualization
- Removal of non-informative identifiers
- Missing-value imputation with KNN
- Feature standardization
- Cluster selection using the elbow method
- Customer segmentation with K-Means
- Cluster profiling and visualization
